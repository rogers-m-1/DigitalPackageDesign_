# Story 1.2: Reference Library - Add Design via STP Upload

## Status

Draft

## Story

**As a** design reviewer,
**I want** to upload a .stp file and save its extracted geometric properties to the reference library,
**so that** I can build up a collection of known designs for future comparisons.

## Acceptance Criteria

1. The user can navigate to a "Reference Library" section of the application.
2. The user can upload a .stp file and provide a name/label for the design.
3. The application extracts the same geometric properties as Story 1.1 (overall length, width, height; bottle cap length, width, height; additional detectable dimensions).
4. The extracted properties are saved to the reference library database, associated with the user-provided name/label.
5. The newly added design appears immediately in the reference library list.
6. If a design with the same name already exists, the user is warned and must confirm before overwriting.
7. The user can delete an existing entry from the reference library.

## Dev Notes

### Dependencies
- Depends on Story 1.1 being complete — STP parsing logic must be extracted into a reusable service/function (not duplicated)
- Reference library database table must be separate from uploaded design / session data

### Key Constraints
- **Multi-user shared system** — reference library visible to all authenticated users
- Same geometric properties extracted as Story 1.1: overall length, width, height; bottle cap length, width, height; additional detectable physical dimensions
- Name/label is user-defined and must be unique within the library across all users
- **Database:** Azure PostgreSQL with concurrent write protection (ensure duplicate names trigger conflict detection, not silent overwrites)
- **File Storage:** Azure Blob Storage for STP uploads to reference library
- **Architecture decisions pending:** Tech stack to be confirmed during architecture phase

### Out of Scope for This Story
- CSV-based library population (Story 1.3)
- Editing an existing library entry's properties (post-MVP)
- User-level access control on library entries

### Testing
- Unit test: STP upload saves correct properties to reference library table
- Unit test: duplicate name check triggers warning
- Integration test: upload → extract → save → appears in library list
- Test file location: 	ests/ at project root
